01 / start here

Get started

Explore a shape without installing anything, or run the comparison locally with Python. The browser planner runs entirely on your device; it is not a flight-control interface.

  1. Open the interactive planner. Choose or draw a field, adjust drone and camera settings, and run the four planners to compare coverage, paths, workload and altitude.
  2. For the local planner, install dependencies from swarm_lab/requirements.txt and run py server.py inside swarm_lab/; open http://127.0.0.1:8765/compare.
  3. For real field input and mission files, follow the field-to-flight manual, not the browser demo.

For the planner algorithms, outputs and local checks, see the repository README.
