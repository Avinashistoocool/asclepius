NIDAR RescueSwarm / guide

From field boundary
to flight plan.

Start in the interactive planner to explore coverage methods. For operational missions, work from a repository checkout and follow the field-to-flight manual; this page is a map to the canonical instructions, not a substitute for its safety checks.

01 / explore

Compare coverage plans

Use the browser planner to draw or choose a shape, configure drones and camera field of view, and compare the medial-axis/chord, lawnmower, harmonic and geodesic plans. This demo runs locally in your browser and does not export or upload missions.

02 / prepare

Generate missions locally

  1. Clone the repository. From swarm_lab/, install the project dependencies with py -m pip install -r requirements.txt.
  2. Draw a field boundary as KML/KMZ or a Mission Planner .poly file. Follow the field-to-flight manual for field selection, launch coordinates, first-flight test mode, and the complete operational checklist.
  3. Use the ArduPilot export reference for mission generation, waypoint output, geofences, and optional MAVLink upload and read-back.

Rehearse before flight: inspect the generated plan, run SITL, and use the manual's pre-flight checks and safety-pilot procedures. The browser comparison does not control aircraft.

03 / monitor

Follow the swarm

The telemetry dashboard guide explains how to monitor tracks, per-drone status and alerts alongside Mission Planner, which remains the primary ground control station.
